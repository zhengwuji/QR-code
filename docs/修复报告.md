# 二维码条码扫描器 2.7.6 终极增强与修复报告

> 本报告汇总自经典 Android 扫码应用 `qrcodereader.barcodescanner.scan.qrscanner`（v2.7.6）的全流程修复、代码瘦身、反馈剥离与功能增强工作。  
> 交付物：桌面 `二维码条码扫描器_修复版.apk`（25.35 MB，正式发布签名，全功能增强）与 GitHub 双版本发布包（Fixed 修复增强版 + Offline 纯离线隐私版）。

---

## 一、本次工程概览与指标对比

在前期完成「闪退修复、图库 Photo Picker 修复、广告桩化、语义化去混淆」的基础上，本次继续实施了完整的深度瘦身与功能增强：

| 维度 | 原版 / 历史修复版 | 本次最终增强版 | 优化幅度 |
|---|---|---|---|

| **用户反馈 / 评分入口** | 存在 7 处入口及邮件外发 | **彻底剥除** | 删除了全部反馈 Activity、Dialog、布局、文案及后台邮件调用 |

## 二、阶段完成明细

### 阶段 1：用户反馈系统与评分漏斗全量移除

针对应用中存在的用户反馈表单、上传截图、意见收集、外发邮件以及星级评分漏斗进行了根治性剥离：

1. **类文件删除（45 个类）**：
   - 反馈页面与回调：`FeedbackActivity` 系列、`ScanFailedFeedbackActivity` 系列、`ScanResultActivity$f` 等；
   - 反馈基类家族：`smali_classes2/W5/`（`QRFeedbackActivity` 系列 14 个类）；
   - 反馈逻辑与邮件工具：`U5/i`（`FeedbackUtil` 邮件组装）、`Y5/a`（`FeedbackManager`）；
   - 图片选择对话框：`X5/`（选图对话框及其全部内部类）；
   - 评分漏斗类：`Ce/v` 系列（`RateUsUtil`）；
   - 关联支持类：`Be/` 桥接、`re/` 失败反馈 lambda、`ze/` 结果页点击桥等。
2. **调用点安全清理 / 桩化**：
   - `ScanResultActivity`：移除 `iv_rate` 绑定，清空 `P0()`、`w0()`、`x0()`、`Z0()` 方法体；
   - `MoreFragment`（设置页）：彻底删除反馈列表项及其点击绑定逻辑；
   - `MainActivity`：中和失败反馈入口与 `RateUsUtil` 调用；
   - `ScanAlbumActivity`：剥除相册解析失败时对反馈邮件的调用；
   - `ScanAlbumFailureDialog`：删除「反馈」按钮绑定逻辑。
3. **资源与清单清理**：
   - 删除 7 个相关布局文件（`activity_feedback.xml`, `layout_dialog_feedback_choose_photo.xml` 等）；
   - 删除 38 个反馈专用 drawable 图标；
   - 清理多语言 `strings.xml` 中全部反馈与打分文案；
   - 从 `AndroidManifest.xml` 中移除相关 Activity 声明。

### 阶段 2：死代码与无用 SDK 全量物理剥离

原包虽在中和阶段屏蔽了广告调用，但仍残留数万个无用 SDK 类文件与 SO 动态库，严重增加体积和安全审计负担。

1. **倒排索引极速簇闭包分析**：
   - 扫描全包 42,559 个类文件，建立双向依赖图谱；
   - 精准计算出孤立不可达死代码集（含 `com/bytedance`, `com/bykv`, `com/pgl`, `com/tiktok`, `com/moloco`, `com/facebook`, `com/my/target`, `com/iab`, `gms/ads`, `exoplayer2`, `firebase` 等）；
   - 彻底物理删除了 **23,066 个死代码 smali 文件**，仅保留 130 个安全的桥接类。
2. **VerifyUtils 彻底拔除**：
   - 历史上的 33 个自杀校验包（`smali_classes4/verify*`，成环互相调用）全部删除；
   - 扫描 19 个 Activity（`Create*Activity` 及 `ScanAlbumActivity`）中的全部 38 处调用点，全部替换为安全桩（`return-void` / `const/4 0`）；
   - 验证全树对 `VerifyUtils` 的引用彻底清零。
3. **资产与动态库裁剪**：
   - 彻底删除 `smali_assets/audience_network/`（3,330 文件）及 `assets/audience_network/` 下两个内嵌 DEX（5.3 MB）；
   - 删除了 8 个架构专用的非必要 so 库（`libbuffer_pgl`, `libsecore`, `libfile_lock_pgl`, `libnms`, `libpglarmor`, `libtt_ugen_layout`, `libapminsighta`, `libapminsightb`），保留核心扫码引擎 `libbarhopper_v3` 和 camera JNI 库。
4. **AndroidManifest.xml 深度清理**：
   - 移除 `AD_ID`, `ADSERVICES` 等广告相关权限；
   - 移除 50+ 个无用广告 Activity、Service、BroadcastReceiver 和 ContentProvider，严格保护 `mlkit` 扫码组件完整性。
5. **瘦身成果**：
   - DEX 类数由 42,592 降至 19,493 类；
   - APK 文件体积由 47.1 MB 直降至 **25.35 MB**。

### 阶段 3：T1 实用体验新特性

1. **音量键开关手电筒**：
   - 在 `smali_classes4/ve/V.smali`（扫码主 Fragment）中新增公开桥接方法 `y4()V`，安全复用内部闪光灯控制链路；
   - 在 `MainActivity.smali` 中重写 `onKeyDown(ILandroid/view/KeyEvent;)Z`，精准捕获 `KEYCODE_VOLUME_UP` (0x18) 与 `KEYCODE_VOLUME_DOWN` (0x19)；
   - 仅在当前处于「扫一扫」Tab 且相机运行状态下响应切换手电筒，其他页面和状态下透明传递给系统原生音量调节。
2. **系统分享识图 (`ACTION_SEND image/*`)**：
   - 在 `AndroidManifest.xml` 为 `MainActivity` 注册 `ACTION_SEND`（MIME 类型 `image/*`）的 `intent-filter`；
   - 在 `MainActivity.smali` 中统一拦截 `onCreate` / `onNewIntent`，提取 `EXTRA_STREAM` 或 `data` Uri；
   - 通过 `BaseFileProvider.l` 转换流，无缝调起 `ScanAlbumActivity.k0` 自动解析，实现从微信、相册、文件管理器一键「分享到扫码器」识图。
3. **桌面长按快捷方式（Shortcuts）**：
   - 新增 `res/xml/shortcuts.xml`，定义三大核心高频入口：
     - **扫一扫**（直达 Tab 1）
     - **创建二维码**（直达 Tab 4）
     - **扫描历史**（直达 Tab 2）
   - 在 `SplashActivity` 注册 `android.app.shortcuts` 元数据，并在 `MainActivity` 恢复时自动完成 Tab 快速跳转。

### 阶段 4：T2 高级功能与深色模式

1. **历史记录 CSV 导出与系统分享**：
   - 新增 `smali_classes4/qrfix/CsvExporter.smali`：
     - 直接通过 Room 数据库单例读取 `qr_scan_history` 表全部记录；
     - 对扫码格式、时间戳、原始文本、解析内容进行标准 CSV 字段转义；
     - 自动附加 UTF-8 BOM 标头，保证 Excel 与各类表格软件打开无乱码；
     - 保存至 Cache 目录并通过 AndroidX FileProvider (`androidx.core.content.c.h`) 授权分享；
   - 在历史记录页顶栏引入分享图标按钮，绑定 `CsvClickListener.smali`，一键弹出系统分享面板，可直接发送到微信、QQ、网盘、邮件或保存至本地。
2. **连续扫码模式**：
   - 新增 `ContinuousScanHelper.smali`：基于 SharedPreferences 维护开关持久化状态；内置 1500ms 防抖算法，避免同一二维码连续触发多次；
   - 在扫码主页底栏新增连续模式长按切换逻辑（`ContinuousToggleListener.smali`），长按即切换并伴随 Toast 提示；
   - 在 `ve/V.smali` 的解码成功回调 `k3` 处插入劫持：连续模式激活时，触发蜂鸣振动提示，异步写入历史数据库，即时清除预览 Overlay 并恢复取景帧解码，不中断扫码流程。
3. **相册批量选图支持**：
   - 调整 `bitmap2/ImageUtil.b(Activity, int)`，在图片选择 Intent 中加入 `Intent.EXTRA_ALLOW_MULTIPLE = true`；
   - 扩展 `MainActivity.onActivityResult`（Request Code `0x65`），支持从 `getClipData()` 中提取多张图片 Uri 进行多选解析。
4. **全面适配深色模式（DayNight）**：
   - 调整 `res/values/styles.xml` 中的 `AppTheme23`，将其父样式升级为 `@style/Theme.AppCompat.DayNight.NoActionBar`，并将 `forceDarkAllowed` 置为 `true`；
   - 新增 `res/values-night/colors.xml`，定义高对比度深色背景（`#121212`, `#1e1e1e`）与柔和浅色文字（`#eeeeee`），界面随系统深色模式自适应切换。

### 阶段 5：纯离线变体、发布签名与 CI 交付

1. **纯离线隐私变体（Offline Variant）**：
   - 扫码核心引擎（ZXing / MLKit Barhopper）完全工作于本地 NDK，不依赖任何云端识别；
   - 通过在清单中完全剥除 `android.permission.INTERNET` 与 `android.permission.ACCESS_NETWORK_STATE`，打造专用 `QRScanner_2.7.6_Offline.apk`；
   - Android 系统级沙箱保证应用无法建立任何网络 Socket 连接，实现绝对纯净与物理离线。
2. **正式发布签名 Keystore**：
   - 生成专用 2048 位 RSA 密钥库 `release.keystore`（别名：`qrscanner`，有效期 10000 天）；
   - 使用 `uber-apk-signer` 签署并对齐 APK，完整通过 v1, v2, v3 签名方案校验；
   - 密钥库妥善隔离，不提交至公共代码仓库。
3. **GitHub Actions 自动化流水线（CI/CD）**：
   - 升级 `.github/workflows/build-release.yml`，在云端 Ubuntu 容器中实现双版本自动编译：
     - `QRScanner_2.7.6_Fixed.apk`（全功能修复增强版）
     - `QRScanner_2.7.6_Offline.apk`（纯离线隐私版）
   - 自动生成 `sha256sums.txt` 校验清单并发布至 GitHub Releases。
